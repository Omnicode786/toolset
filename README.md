# Tool Set Website

A React and Vite website for browsing premium digital tool subscriptions.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.

## React pages

- Home
- About Us
- Subscriptions
- Reviews
- Blogs
- Contact

## Catalogue

The product catalogue is managed from `src/data/constants.js`. It contains the exact plan names and PKR prices supplied in the rate list, along with short descriptions of how each tool is commonly used.

The existing visual theme and page layout are preserved. Responsive safeguards are included for desktop, tablet, mobile and narrow mobile screens.
